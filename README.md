# Hosts Aggregator

Инструмент для автоматической сборки, дедупликации и агрегации нескольких hosts-файлов в единый оптимизированный список.

## Назначение
Используется для блокировки рекламы, телеметрии и нежелательных доменов на уровне DNS/hosts без необходимости вручную склеивать десятки разных источников.

## Особенности
- Автоматическая очистка от дублей и комментариев.
- Сборка по актуальному расписанию через CI/CD.
- Готовый к употреблению единый файл блокировок.
