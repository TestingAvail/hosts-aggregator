# Hosts & ABP Aggregator

Автоматический пылесос для блокировки рекламы, трекеров и всякого соевого мусора на уровне DNS. Скрипт сам выкачивает разрозненные списки, выжигает дубликаты и собирает в чистые файлы через GitHub Actions.

## Что качать?

Выбор зависит от того, сколько оперативки у твоего железа:

* **`*-slim.txt`** — для слабых роутеров с 256 МБ ОЗУ, которые иначе подавятся и уйдут в ребут от огромной портянки.
* **Обычные файлы (`hosts.txt` / `abp.txt`)** — для нормальных железок с 512+ МБ оперативки или десктопов, готовых схавать весь объем блокировок.

## Форматы

* **`hosts.txt` / `hosts-slim.txt`** — для `/etc/hosts` или роутера.
* **`abp.txt` / `abp-slim.txt`** — в формате Adblock Plus для блокировщиков.
* **`*.sha256`** — контрольные суммы для проверки целостности.
